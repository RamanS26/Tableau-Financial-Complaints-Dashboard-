# Tableau-Financial-Complaints-Dashboard-
## Project Objective :  
Built an interactive Tableau dashboard to analyze over 75,000 customer complaints and help identify common issues, track company response times, and understand how complaints are being resolved. 

## Dataset Used :
- <a href="https://github.com/RamanS26/Tableau-Financial-Complaints-Dashboard-/blob/main/financial-consumer-complaints.csv">Dataset</a>

## KPI (Questions):
- How many total complaints were filed?
- Are companies responding to complaints on time?
- How many complaints are currently unresolved?
- What percentage of cases are resolved without financial compensation?
- Which financial products receive the most complaints?
- What are the most common complaint issues?
- How many customers dispute the company's resolution?
- Which states have the highest complaint volumes?
